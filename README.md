# 🎓 Internship Management Portal

A modern Internship Management Portal built using **React.js** and **Vite** that allows students to explore internships, apply for positions, take online assessments, and track application status. It also includes an Admin Dashboard for managing applications and updating recruitment statuses.

🌐 **Live Demo:** https://internship-management-portal-final.netlify.app/

---

## 📖 Project Overview

The Internship Management Portal is designed to simplify the internship recruitment process for both students and administrators.

### Students can:
- Register and log in securely
- Browse available internships
- Apply for internships
- View submitted applications
- Take online assessments
- Track application status

### Administrators can:
- View all student applications
- Monitor dashboard statistics
- Search applications
- Update recruitment status
- Manage the recruitment workflow

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/chandrakala-utla/internship-management-portal.git
```

Move into the project folder

```bash
cd internship-management-portal
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build the project

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
